# 🔦 Хозяин маяка

Уютная инкрементальная (idle) игра-PWA. Ты — смотритель маяка: касайся фонаря, покупай огни, открывай моря, делай **отливы** (престиж → 🦪 жемчужины) и **вознесения** (второй слой → ⭐ звёзды).
Vanilla HTML/CSS/JS, без сборки, без бэкенда, работает офлайн. Вся графика (canvas/SVG/эмодзи) и звук (WebAudio) созданы кодом.

- Играть: https://nikitadob123-bit.github.io/mayak-idle/
- Тесты логики: `npm test` · Симуляция баланса: `npm run sim` · E2E (Chrome): `npm run e2e` · Иконки: `npm run icons`
- Структура: `js/util.js` (числа) · `js/data.js` (контент и баланс) · `js/engine.js` (чистая логика) · `js/save.js` (сохранения) · `js/ui.js`, `js/scene.js`, `js/audio.js`, `js/main.js`
